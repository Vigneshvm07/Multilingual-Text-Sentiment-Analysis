ABOUT PROJECT

Multilingual NLP for global communication

Multilingual Text Sentiment Analysis is an NLP-based system designed to identify the emotional polarity of text written in different languages.

The project demonstrates how natural language processing can be applied to customer reviews, social media posts, feedback, surveys, and multilingual communication.
